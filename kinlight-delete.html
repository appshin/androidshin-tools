Kinlight 계정 연결 해제 및 데이터 삭제
Account & Data Deletion

앱 · App: Kinlight (com.appshin.kinlight)  |  개발자 · Developer: Mr.AndroidShin

한국어English

Kinlight에는 별도의 회원가입이나 개발자 서버가 없습니다. ‘계정’은 어르신 본인의 카카오 계정과 Kinlight의 연결을 뜻하며, 모든 앱 데이터는 휴대폰 안에만 저장됩니다.

방법 1. 앱에서 바로 삭제 (권장)

  1. Kinlight 홈 화면 오른쪽 위 톱니바퀴를 1초 동안 누릅니다. (녹색 링이 다 차면 열립니다)
  2. 보호자 메뉴 맨 아래 카카오 연결 해제 및 데이터 삭제를 누릅니다.
  3. 확인 창에서 삭제를 누르면 카카오 연결이 끊기고 앱의 모든 데이터가 즉시 삭제됩니다.
  4. 필요하면 앱을 삭제합니다.

방법 2. 앱 없이 삭제

  1. 카카오톡 › 설정 › 카카오계정 › 연결된 서비스 관리 › Kinlight › 연결 끊기
  2. 휴대폰 설정 › 앱 › Kinlight › 저장공간 › 데이터 삭제 (또는 앱 삭제)

방법 3. 이메일 요청

contact@androidshin.dev 로 “Kinlight 데이터 삭제 요청”을 보내 주시면 위 절차를 안내해 드립니다. 개발자는 서버에 사용자 데이터를 보관하지 않으므로, 개발자 측에서 별도로 삭제할 데이터는 없습니다.

계정은 유지하고 일부 데이터만 삭제

  • 안심 구역: 보호자 메뉴 › 안심 구역에서 휴지통으로 개별 삭제
  • 이름·전화번호·주소: 보호자 메뉴 › 기본 정보에서 지우거나 수정 후 저장
  • 위치 전송 중지: 보호자 메뉴 › 공유 중지
  • 보낸 위치 메시지: 카카오톡 ‘나와의 채팅’에서 메시지를 길게 눌러 삭제

Kinlight has no sign-up and no developer server. The “account” is the connection between the senior's own Kakao account and Kinlight; all app data is stored only on the phone.

Option 1. Delete in the app (recommended)

  1. On the Kinlight home screen, hold the gear icon (top right) for 1 second until the green ring fills.
  2. At the bottom of the Guardian menu, tap Disconnect Kakao & delete data.
  3. Tap Delete to confirm. The Kakao connection is removed and all app data is deleted immediately.
  4. Uninstall the app if you wish.

Option 2. Delete without the app

  1. KakaoTalk › Settings › Kakao Account › Connected services › Kinlight › Disconnect
  2. Phone Settings › Apps › Kinlight › Storage › Clear data (or uninstall)

Option 3. Request by email

Email contact@androidshin.dev with “Kinlight data deletion request” and we will guide you. The developer keeps no user data on any server, so there is nothing to delete on the developer side.

Delete some data without disconnecting

  • Safe zones: Guardian menu › Safe zones › trash icon
  • Name, phone numbers, address: Guardian menu › Basic information › edit or clear, then Save
  • Stop sending locations: Guardian menu › Stop sharing
  • Sent messages: long-press a message in KakaoTalk “Chat with myself” and delete it
